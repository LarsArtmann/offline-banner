## Unreleased

The banner learns which limb is numb: reachability stops being one boolean.

- **Four independent probe legs + the phase ladder** — icmp (the original\n  ping) is joined by a tcp leg (raw connect, IP literal, different anycast\n  provider) and a dns leg (`getent`, the resolver applications actually use).\n  A leg down while others are up is **degraded**: a silent info strip naming\n  the down legs, auto-fading after `degradedDwellSeconds` — no alarm, no\n  ledger. The yellow offline alarm now means a genuinely unusable network.\n  Born live: one host's gateway policed ICMP so hard a single-leg banner\n  cried offline 206 times in 8 hours over a usable network.\n- **Additive state keys** — `phase`, `legs`, `degradedLegs`, `degradedVisible`\n  ride the state file and journal (`banner phase=… legs=…`); a bar consumer\n  renders the ladder, and a `waybar-consumer` check pins its full rendering\n  matrix with 12 fabricated-state fixtures.\n- **The PATH-phantom gate** — the first live deploy of the legs shipped a unit\n  PATH whose `getent` did not exist and every name-grep check stayed green\n  while the dns leg failed every probe. The module-contract check now\n  RESOLVES `timeout`/`getent`/`ping` against the rendered PATH.\n- **CI-honesty fixes** — state writes are atomic (tmp + rename); the\n  probe-transition harness polls state reads (`assert_state_jq`) and resets\n  its scenario control files, closing the emulated-aarch64 flake class.\n\n## 0.2.0 — 2026-10-29

The banner learns to speak and to remember.

- **Sound cues** — one synthesized cue per outage transition (never per probe),
  a lower droop for link loss than net loss, a sparkle on recovery. Three
  build-time themes (`chime`, `droplet`, `retro`) with no audio assets, plus
  `soundTheme`/`soundVolume`; `"none"` for silence.
- **Persistent outage ledger** — one JSON line per completed outage in
  `~/.local/state/offline-banner/history.jsonl`, so outages outlive reboots.
  `enableHistory`/`historyPath`; blips, open outages, and demo runs never write.
- **Structured journal tokens** — `banner state=…`, `probe ok|failed`, and
  `outage ended from=… duration=…` are now the stable, grep-able surface. The
  state file gained `since` (current outage start).
- **New checks** — `render-smoke` proves the strip's pixels in headless sway,
  and `shell-content` asserts the built QML keeps its namespace, env seams, and
  the full synthesized WAV matrix.
- A reference waybar consumer (`contrib/offline-banner-waybar`), a project
  website, and a 24 s demo video.

## 0.1.0 — 2026-10-17

Initial release: `services.offline-banner` NixOS module with v3 behavior —
static yellow top-strip on every monitor, carrier-glob + ICMP probe (not
`nmcli`), 2-failure debounce, top-layer push-down animation, last-online
caption, click-to-dismiss, demo mode, structured journal lines + JSON state
file, systemd sandbox hardening (contract-checked line-by-line), and six flake
checks including a probe-transition machine test.

See the [full changelog](https://github.com/LarsArtmann/offline-banner/blob/master/CHANGELOG.md)
for the Fixed and Security sections.
