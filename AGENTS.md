# offline-banner: Agent Guide

Yellow top-strip offline banner for NixOS desktops — `github:LarsArtmann/offline-banner` (public repo created and pushed 2026-10-16).

## Identity

- One NixOS module, one file: `module.nix` (`services.offline-banner`, systemd **user** service, second-Quickshell-instance pattern — Quickshell runs the inline `shell.qml`; no dependency on any bar/shell plugin).
- Extracted from SystemNix 2026-10-16 (`modules/nixos/desktop/offline-banner.nix`, deployed there as gen 904 v1 — verified 2026-10-17: SystemNix live-session report anchors `/run/current-system == 904` + `system-904-link`; gen 904 shipped v1, v2/v3 were demo-proven only and ride SystemNix's next switch). SystemNix is the origin of every behavior doctrine (non-flashing yellow, debounce, fail-visible probe, push-down animation) — the rationale comments in `module.nix` are the contract; do not silently drop them when refactoring.

## Hard rules

- **The module stays single-file and self-contained** (QML inlined via `pkgs.writeTextDir`). Extracting the QML into a store file is allowed only if the env-var contract below survives unchanged.
- **The `OFFLINE_BANNER_*` env vars are a public surface** (live-tuning via drop-in, demos, the pending VM test's probe injection): the four probe vars, the legs additions (`OFFLINE_BANNER_TCP_HOST/TCP_PORT/DNS_NAME`, `OFFLINE_BANNER_DEGRADED_DWELL`), the sound/history additions (`OFFLINE_BANNER_SOUND_THEME/SOUND_VOLUME/SOUNDS`, `OFFLINE_BANNER_HISTORY`), and `OFFLINE_BANNER_STATE_DIR` (renames the state DIR under XDG_RUNTIME_DIR, name only). Unit-managed env is asserted by `module-contract`; app-only siblings `OFFLINE_BANNER_SMOKE_{PROBE_HOST,DEMO,SOUND}` tune `nix run .#smoke`. When UNSET (bare `quickshell -p`, tests, demos) sound and history stay inert.
- **Never embed shell/JS parameter expansion (`${`-style) or a literal `''` in the inlined QML or check scripts** — Nix's lexer silently corrupts the former (observed 2026-10-28: `${n:-0}` in a check script rendered as `n:-0` with NO eval error) and the latter terminates the indented string outright. Escape as `''${` where a literal is truly needed; prefer POSIX-safe guards.
- **Nix '' string escaping**: `\"` sequences in the probe JS are literal and required; no `${` in QML/JS except intended Nix interpolations (`${cfg.layerNamespace}`); a heredoc emitted from a Nix string MUST use a quoted delimiter (`<<'EOF'`); multi-repo work passes ABSOLUTE paths everywhere; where the tool shell blocks `systemctl`, busctl D-Bus calls substitute (`Manager.RestartUnit ss <unit> "replace"`; Stop needs the mode too). Full write-ups: docs/agent-notes.md and crush-config `references/lessons.md`.
- 2-space indentation; `nix fmt` (treefmt: nixfmt + statix) is the ONLY style arbiter and covers `.nix` only. Markdown is hand-formatted by deliberate decision (2026-10-17): status/planning docs are point-in-time snapshots, never machine-reflowed. **D4 EXECUTED 2026-11-23**: a real `.buildflow.yml` skips `dprint-format`, `prettier-format` and `nix-fmt` (rationale in the file; `config lint` clean), and the BuildFlow-dropped `dprint.json` is deleted and gitignored — that config machine-reflowed the markdown corpus twice (the 21-46:16 space-strip; the 2026-11-23 strike-renumbering finding). `shfmt` stays. Do NOT install BuildFlow's pre-commit hook. The fleet-wide fix (skip non-managed repos by default) is still an upstream BuildFlow task.
- `probeTimeoutSeconds < checkIntervalSeconds` is an eval-time assertion — keep it.
- **Resolve, don't grep, the rendered unit PATH** (the PATH-phantom class, 2026-11-10): any check claiming "tool X is available to the unit" must RESOLVE X against the rendered PATH (`PATH=<extracted> command -v X` in a runCommand over the unit text file), never grep the unit text for the tool NAME. `module-contract`'s PATH-phantom gate is the pattern; negative-tested at both layers. Story: docs/agent-notes.md.
- **Recompute leg state from raw counters inside change handlers and `emitState`** — chained `var`/computed bindings read STALE mid-cascade, and even a var-binding's CHANGED-SIGNAL is not contract-truth (both CI-proven; see docs/agent-notes.md). `rawDownLegs()` is the only truth for leg state; bindings render, functions decide; the degraded re-arm compares the raw set (`lastDownLegsKey`).
- **Journal asserts: exact counts only at deterministic positions; state-file reads always poll** — an exact `failures=N/2` grep is deterministic ONLY from a controlled start (fresh instance, single failing leg, monotone per-probe counters); past that, assert the TRANSITION (`assert_journal_re`, reason + counter-advanced). The state file is written by a spawned `sh` — a single read after a journal match is never evidence (it can lag the line AND catch the file mid-rewrite; the empty-file tear was CI-proven x86_64 2026-11-10 before the atomic tmp+mv write): poll via `assert_state_jq`/`assert_state`.
- **Check scripts run under stdenv's `set -euo pipefail`** (silent-death class, 2026-11-24): any `cmd 2>/dev/null | other` whose left stage can fail (a legitimately-absent file) makes the pipeline fail under pipefail, the assignment fails under set -e, and the builder exits 1 with a ZERO-line log — no assert message, nothing to grep. Guard the SUBSTITUTION (`wc -l 2>/dev/null < "$f" || echo 0`), not just the stream; redirections apply left-to-right, so put `2>/dev/null` FIRST to swallow the redirect error. probe-transitions sat red for a day on this shape while every sibling stayed green (the flap ledger is legitimately absent pre-close). Trace-verified via a `set -x` probe anchored INSIDE the dying script (the first instrumentation attempt anchored on the wrong check's identical opening — always verify the landed location).

## Runbooks

### Live smoke test (hardened unit without a NixOS switch)

Runs the exact serviceConfig sandbox as a transient user unit. Bus-transient properties do NOT expand specifiers (the `%t` expansion above is unit-file-only), so runtime paths are literal. The transient therefore cannot exercise the `%h` ledger hole at all — and unit-verify cannot see its runtime failure — so only a real unit start proves provisioning (that blind spot shipped the 2026-11-05 crash loop). Prefer the versioned form, which closes the hole: **`nix run .#smoke`** derives every property from the rendered serviceConfig and substitutes `%h`→`$HOME`/`%t`→`$XDG_RUNTIME_DIR` (override the probe with `OFFLINE_BANNER_SMOKE_PROBE_HOST=192.0.2.123`, force-show with `OFFLINE_BANNER_SMOKE_DEMO=1`, audition cues with `OFFLINE_BANNER_SMOKE_SOUND=1`). Since smoke-isolation it runs on `*-smoke` dirs, so it is SAFE beside the live unit (no shared writable namespace; its stop cannot orphan the live unit's binds). The hand recipe below stays for reference. Ground-truth store QML dir: extract exactly as `scripts/capture-demo.sh` does (third word of the eval'd `ExecStart`).

```bash
uid=$(id -u)
systemd-run --user --unit=offline-banner-smoke \
  -p ProtectSystem=strict -p ProtectHome=read-only -p PrivateTmp=true \
  -p RuntimeDirectory="offline-banner quickshell" -p RuntimeDirectoryMode=0700 \
  -p ReadWritePaths="/run/user/$uid/offline-banner /run/user/$uid/quickshell" \
  -p MemoryMax=256M \
  -p Environment="OFFLINE_BANNER_PROBE_HOST=127.0.0.1" \
  -- quickshell -p "$qml"
```

Checklist: unit active under the full sandbox; ping works with cap_net_raw (`probe ok` for 127.0.0.1); forced outage (restart with `OFFLINE_BANNER_PROBE_HOST=192.0.2.123`) → journal `banner state=shown reason=net` + `{"active":true}` in `$XDG_RUNTIME_DIR/offline-banner/state`; demo control (`OFFLINE_BANNER_DEMO=1`) → `{"active":true,"demo":true}`; RSS well under MemoryMax; fontconfig cache warnings gone (XDG_CACHE_HOME lands in the runtime dir). Transient runs carry NO sound/history env → both stay inert; to hear the cues live, add `-p Environment="OFFLINE_BANNER_SOUND_THEME=chime"` plus `OFFLINE_BANNER_SOUNDS` pointed at the extracted store dir. `systemctl --user stop` when done — RuntimeDirectory cleans up with the unit.

Post-switch ritual (after any SystemNix switch deploys a new lock): `nix run .#smoke` (runbook 1b), `scripts/click-dismiss-proof.sh` on the real output, then one journal sweep over the fresh instance — zero `Failed at step`, state heartbeat fresh, and if a real outage fired a cue, ZERO `pw-play exit=` lines (that is the cue-FIRED signature; audibility stays an ears-on owner check — the TODO ears row). Verified live end-to-end 2026-11-18 on evo-x2 (after fixing three latent runtime bugs, `41b3f49`): transient started, rendered the demo strip on the real monitor, journaled `banner state=shown` demo:true, stopped clean. The shared-runtime-dir hazard is FIXED by smoke-isolation (isolated `*-smoke` dirs); the capture recipe (WAYLAND_DISPLAY, grim -t ppm, hue-aware band detector) lives in the scripts and agent notes.
