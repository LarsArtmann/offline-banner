02Why Nothing Was Adopted

The fleet argument, settled

The owner maintains many projects with limited time; a project that re-integrates every sibling library spends its life fixing integration bugs instead of benefiting from collective improvements. The verdicts above are the disciplined version of that trade: offline-banner has no Go toolchain, so adopting any of these libraries would add a build system to host code nothing executes — pure bug surface, zero capability. Refusing that is not under-utilization; it is the correct maximization: the fleet's improvements land in this repo as doctrine (see below) at zero maintenance cost, and this repo's fixes never destabilize a Go consumer.

Honesty notes: (1) the only consumer references to any library name are 8 doc-only prose mentions (LICENSE-convention notes in TODO_LIST.md and archived status docs: go-atomic-write 3, cmdguard 2, templ-components 2, go-cqrs-lite 1) — zero in code or config; (2) every evidence grep excludes docs/review/** so the reports do not match themselves — run them from the repo root, or the relative glob stops matching (an rg CWD subtlety the verify appendix pins); (3) the unit runs Restart = "always" (module.nix:1162), not on-failure — caught and corrected mid-run.

03Doctrine Carries

Five places where this repo independently implements a fleet library's core principle in QML/sh/systemd form — the non-Go channel through which collective improvement actually reaches this project.

+
Stage to a unique temp, one rename (go-atomic-write) The state-file recipe (module.nix:594) already implements the safe core — and CI proved the failure mode (the 2026-11-10 empty-file tear) before the library named it. The contract comparison surfaced one real gap, routed below.
+
Supervision belongs to the service manager (go-daemon) systemd IS the daemon story: Restart = "always", MemoryMax, RuntimeDirectory cleanup, journal capture. go-daemon's own docs defer supervision to systemd; the repo refused double supervision for the same reason.
+
Polling + heartbeat is positive liveness (go-filewatcher) A file watch cannot see a dead writer; the updatedAt heartbeat + OFFLINE_BANNER_MAX_AGE staleness check (contrib consumer) is a liveness signal only a poller computes — and the library's own WithPolling backend treats polling as first-class.
+
Deduplicate on committed state, not signals (go-idempotency) The QML re-arm compares the raw down-leg set (lastDownLegsKey) and suppresses same-content firings — CheckAndRecord-thinking applied to event dedup, CI-pinned after a degraded re-show false positive.
+
Classify before string-matching (go-error-family) Journal lines carry machine-parseable reason= classes asserted by regex (assert_journal_re), never prose — "share the protocol, not the implementation" in journal form; presentation (degraded ladder) follows classification.
